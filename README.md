# Personal Engineering Portfolio

A responsive personal portfolio website built with semantic HTML5 and CSS3 to showcase my engineering projects, skills, and contact information.

## 🛠️ Features & Technologies

- **Semantic HTML5:** Clean layout structured with native elements for web accessibility and standards.
- **Custom CSS3 Styling:** Responsive styling and structured layout for an interactive visual experience.
- **Media Demonstrations:** Embedded video walkthroughs and audio resources.
- **Interactive Contact & Socials:** Direct form integration alongside secure external links (Email, LinkedIn, GitHub).
- **Smooth Navigation:** In-page anchor links for fast section jumping.
